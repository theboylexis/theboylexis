## Featured Projects

### ⚡ [FPGA-Synthesizable 8-Bit CPU](https://github.com/theboylexis/FPGA-Synthesizable-8Bit-CPU)

Custom multi-cycle 8-bit processor designed in Verilog with a **16-bit instruction format** and **13-instruction ISA**.

Highlights:

- RTL design from scratch
- custom datapath and multi-cycle control unit
- module-level and full CPU verification
- 13 / 13 assigned instructions verified in simulation
- synthesized and implemented on a **Sipeed Tang Nano 20K**
- physically validated using arithmetic, memory, and control-flow programs
- hardware bring-up included LED debugging, input synchronization, and pushbutton debounce logic

`Verilog` `FPGA` `RTL Design` `Computer Architecture` `Icarus Verilog` `GOWIN EDA`
